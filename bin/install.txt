REALBOT2 2.1.0 - Counter-Strike 1.6
===================================

REALBOT2 is a server-side Counter-Strike 1.6 bot based on RealBot by
Stefan Hendriks. It is a Metamod plugin.

REQUIREMENTS
------------
- Counter-Strike 1.6 (Steam or a compatible dedicated server)
- Metamod 1.19 or newer
- Windows: cstrike/addons/realbot2/dll/realbot2_mm.dll
- Linux:   cstrike/addons/realbot2/dll/realbot2_mm_i386.so

INSTALL
-------
REALBOT2 is installed entirely inside the cstrike folder. It does not
create a realbot2 folder at the Half-Life root.

1. Unpack the release ZIP into your Half-Life root folder (the folder
   that contains cstrike). The ZIP already contains a cstrike folder,
   so you should get:

     Half-Life\cstrike\addons\realbot2\dll\realbot2_mm.dll
     Half-Life\cstrike\addons\realbot2\dll\realbot2_mm_i386.so
     Half-Life\cstrike\addons\realbot2\data\
     Half-Life\cstrike\realbot2_keys.cfg

   If you only have a cstrike folder, extract the contents of the ZIP's
   cstrike directory directly into it.

2. Add REALBOT2 to cstrike\addons\metamod\plugins.ini:

     win32 addons/realbot2/dll/realbot2_mm.dll

   On Linux:

     linux addons/realbot2/dll/realbot2_mm_i386.so

3. Add this line to cstrike\autoexec.cfg:

     exec realbot2_keys.cfg

   (Or type it once in the client console.)

4. Start a listen server. Press KP_INS (numpad 0 / Insert) to open the
   REALBOT2 numeric-keypad menu. Numpad 1-9 selects items, KP_PLUS and
   KP_MINUS change pages, KP_DEL closes the menu.

The menu is available to the listen-server host only. On a dedicated
server use the realbot2 console/RCON commands, for example:

     realbot2 add
     realbot2 add 1 5
     realbot2 remove 3
     realbot2 skill -1
     realbot2 max 15

UPGRADING FROM 2.0.0
--------------------
Version 2.0.0 used a realbot2 folder at the Half-Life root. To upgrade:

1. Move realbot2\dll and realbot2\data into cstrike\addons\realbot2\.
2. Change plugins.ini to the new path shown above.
3. Keep cstrike\realbot2_keys.cfg where it is.

Existing waypoint files, personality files and learned data in
realbot2\data can be copied into cstrike\addons\realbot2\data.

NOTES
-----
- Bots learn maps over time. Walk around a new map before adding many
  bots, or install existing .rbn waypoint files for popular maps.
- The old "realbot" console command is kept as an alias for "realbot2".
